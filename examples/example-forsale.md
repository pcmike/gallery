### How this maps to your photo filenames

For the auto-linked thumbnails and colored/status gallery boxes above to work, name your photos so each item's filename prefix matches a word used in its paragraph, e.g.:

```
widgeta_01.jpg, widgeta_02.jpg   -> matches "Widget Model A" via the word "widgeta"
widgetb_01.jpg                   -> matches "Widget Model B" via "widgetb"
widgetc_01.jpg, widgetc_02.jpg   -> matches "Widget Model C" via "widgetc"
```

The match is a plain, case-insensitive, whole-word search — no special tagging needed, just make sure the filename prefix appears somewhere in that item's paragraph text.
