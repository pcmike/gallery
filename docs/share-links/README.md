# Share links (2.3.0)

Temporary links such as `https://example.com/trip/k7QpR2mXv9LwTb4e` that sign a person in as a private viewer: limited by number of opens and/or by a start and end time, optionally limited to chosen folders or photos, with a log of who looked at what.

- [DECISIONS.md](DECISIONS.md): **why** each choice was made (the conversation, condensed). Read this first.
- [PLAN.md](PLAN.md): how it is built, the milestones (with check boxes), the call-site checklist and the test plan.
- [PHONE-CHECKLIST.md](PHONE-CHECKLIST.md): what to check on a real phone (the things that can't be tested from here).
- [mockups/](mockups/): pictures of every screen (`png/`) and the scripts that drew them (`generators/`).

Status lives in the check boxes in PLAN.md (built; waiting for the owner's phone check and the release). This folder describes work on branch `v2.3.0-dev`; it is not part of the shipped `index.php`.
