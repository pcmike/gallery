# Gallery user guide

The manual for [Gallery](../../README.md). Each page is a part of what used to be one long README; the text is the same, split by what you are trying to do.

| Page | What is in it |
|---|---|
| [Getting started](getting-started.md) | Requirements, first run, and a recipe for each way people use it: a plain gallery, a for-sale listing, a trip album, private photos, an archive on another disk, iPhone photos. |
| [Settings](settings.md) | Every setting with its default, the settings file, and how the admin saves them. |
| [Notes, folders and the viewer](notes-and-folders.md) | Markdown notes and directives, folders (cover cards or Flat), video, captions and locations, photo order, the viewer, thumbnails and phones, maps. |
| [The admin](admin.md) | First run and signing in, staying signed in, the list of browsers, the shell, the Health check, passwords, and the files the gallery makes. |
| [Private items, share links and sharing](private-and-sharing.md) | Hiding photos, share links in full (options, addresses, closing the public gallery, the log), downloads, and how links preview when shared. |
| [The server](server.md) | Locking down the data and photo files for nginx and Apache, troubleshooting, and the security notes. |
| [Upgrading and backups](upgrading.md) | The upgrade notes for each version, and what to back up. |

Also in the repository: the [CHANGELOG](../../CHANGELOG.md), an [example notes file](../../examples/example-forsale.md) and an [example settings file](../../gallery-config.example.php).
